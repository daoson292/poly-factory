# Poly Factory

Hệ thống quản lý xưởng nội bộ (FPL Poly Factory).

## Kiến trúc dự án
- **Backend:** NestJS / TypeScript
- **Frontend:** React / Vite / Tailwind CSS
- **Mini App:** Zalo Mini App integration
- **Hạ tầng:** Docker Compose, Nginx Reverse Proxy

## Cài đặt & Khởi chạy
```bash
docker-compose up -d
```
